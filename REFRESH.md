# Maintaining and refreshing the package

The public repository is the maintained source for the 0.2.0 package. The earlier two-file snapshot is superseded by a complete skill folder. Changes are reviewed here; installed copies are snapshots and are not automatically updated.

Copy the entire `skills/india-dpdp-audit/` folder when installing or refreshing. Preserve its licence and Required Notice. Do not refresh by copying an older local two-file skill over this repository. No installed agent configuration is changed by the test or report commands.

Update the legal-source review date only for sources actually checked, and retain inaccessible-source and exact-date uncertainty. A code release is not a legal re-verification. Update the package version in the skill when packaging changes; update the schema version when the output contract changes incompatibly.
